| ফাইল | কী আছে |

Feature আগে থেকে আছে কি না, তার উত্তর [timeline.md](timeline.md)। [architecture.md](architecture.md) শেষ চেহারা। প্রথম অধ্যায়ের system ওই ছবি নয়।
